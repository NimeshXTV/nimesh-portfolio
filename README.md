# Nimesh Sharma

Personal portfolio and blog — writing about data, systems, and learning.

## What's here

* Home page with what I do
* Writing about data, systems, and learning
* Projects and links
* Ways to reach me

## Tech

Built with Astro. Styled with Tailwind CSS.

## Running locally

```bash
npm install
npm run dev
```

Then open `http://localhost:4321`.

## Building

```bash
npm run build
npm run preview
```

## Deploying

Push to GitHub, connect to Vercel. Done.
